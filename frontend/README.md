# Frontend - AI Interview Ready

React + Vite + Tailwind CSS client for the AI Interview Ready platform.

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

The app runs on <http://localhost:3000> and calls the backend at
<http://localhost:5001/api>.

## Scripts

```bash
npm run dev      # start Vite
npm run build    # production build
npm run lint     # run ESLint
npm run preview  # preview the production build
```
